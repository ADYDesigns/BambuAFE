Printers
The controller talks directly to your printers over your local network, so it must be on the same network as them. Click Find printers to search the network, then pick which slot each printer goes in. The only thing you have to type is each printer's access code, found on the printer's touchscreen in its network settings. If a printer's IP address ever changes the controller will find it again by its serial number.
